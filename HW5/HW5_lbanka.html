  3. Now write a quick function that allows the user to easily query this API. The inputs to the function should be the title/subject to search for (string), a time period to search from (string - you’ll search from that time until the present), and an API key.

    Solution:

    # Create a function to search NewsAPI
search_news <- function(subject, from_date, api_key) {

  # Send a request using the inputs provided
  response <- GET(
    "https://newsapi.org/v2/everything",
    query = list(
      q = subject,
      from = from_date,
      language = "en",
      pageSize = 50,
      apiKey = api_key
    )
  )

  # Stop if the API request fails
  stop_for_status(response)

  # Parse the response
  result <- content(
    response,
    as = "parsed",
    simplifyVector = FALSE
  )

  # Return the articles
  result$articles
}
