Part 4: Fitting Multiple Linear Regression Models

Recipe 1: Basic Model

For the first model, I created a recipe to prepare the data for linear regression. I used the date to create a weekday or weekend variable and removed the date from the predictors. I also standardized the numeric predictors and created dummy variables for the categorical variables.

recipe1 <- recipe(bike_count ~ ., data = bike_train) |>
  step_date(date, features = "dow") |>
  step_mutate(
    day_type = factor(
      if_else(date_dow %in% c("Sat", "Sun"),
              "Weekend", "Weekday")
    )
  ) |>
  step_rm(date, date_dow) |>
  step_normalize(all_numeric_predictors()) |>
  step_dummy(all_nominal_predictors())

Recipe 3: Adding Quadratic Terms

For the third recipe, I kept the interactions from Recipe 2 and added squared terms for standardized temperature and humidity. This allows the model to capture possible curved relationships with bike rentals.

recipe3 <- recipe(bike_count ~ ., data = bike_train) |>
  step_date(date, features = "dow") |>
  step_mutate(
    day_type = factor(
      if_else(date_dow %in% c("Sat", "Sun"),
              "Weekend", "Weekday")
    )
  ) |>
  step_rm(date, date_dow) |>
  step_normalize(all_numeric_predictors()) |>
  step_dummy(all_nominal_predictors()) |>
step_interact(
  terms = ~ starts_with("seasons_"):starts_with("holiday_") +
    starts_with("seasons_"):temp +
    temp:rainfall
) |>
step_mutate(

Conclusion

In this homework, I used the Seoul Bike Sharing dataset to compare multiple linear regression models and a regression tree for predicting daily bike rentals.

Among the linear regression models, Model 3 performed the best. It included interaction terms and quadratic terms for temperature and humidity.

The final linear regression model had a test RMSE of approximately 3,059 and MAE of 2,132. The regression tree had a higher RMSE of 3,814 and MAE of 2,866.

Overall, the linear regression model performed better on the test data. This suggests that the interaction and quadratic terms helped capture the relationships in this dataset better than the regression tree.
