Creating Daily Data

I combined hourly observations into daily observations. I used the sum for bike rentals, rainfall and snowfall and the mean for the other weather variables.

bike_daily <- bike_data |>
  group_by(date, seasons, holiday) |>
  summarize(
    bike_count = sum(bike_count),
    rainfall = sum(rainfall),
    snowfall = sum(snowfall),
    temp = mean(temp),
    humidity = mean(humidity),
    wind_speed = mean(wind_speed),
    visibility = mean(visibility),
    dew_point_temp = mean(dew_point_temp),
    solar_radiation = mean(solar_radiation),
    .groups = "drop"
  )

Part 3: Splitting the Data

I split the daily dataset into training and testing sets. I used 75% of the data for training and 25% for testing. I also used seasons to keep the seasonal distribution similar in both sets.

set.seed(558)

bike_split <- initial_split(
  bike_daily,
  prop = 0.75,
  strata = seasons
)

bike_train <- training(bike_split)
bike_test <- testing(bike_split)
