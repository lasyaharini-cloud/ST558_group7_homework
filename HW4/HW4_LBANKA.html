  1. What is meant by long format data and wide format data? Which do we generally prefer for statistical analysis?

    Solution:

    Long format is known as tidy format, since it has each row representing a single observation and each variable in its own column. This is preffered for statistical analysis because it makes data easier to filter, group and analyze. Wide format has each row representing one unit, with its different measurements across multiple columns.
